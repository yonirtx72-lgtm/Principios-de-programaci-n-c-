CURSO

Biblioteca de C++

Aprende concepto por concepto.

01 // SINTAXIS

Tu primer programa

C++ comienza normalmente desde la función main(). La biblioteca iostream permite mostrar información en pantalla. 

#include <iostream>

int main() {

    std::cout << "Hola mundo";

    return 0;
}
02 // VARIABLES

Variables y tipos de datos

Una variable almacena información. Los tipos comunes incluyen int, double, char, bool y string. 

#include <iostream>
#include <string>

int main() {

    int edad = 15;
    double precio = 99.99;
    char letra = 'A';
    bool activo = true;
    std::string nombre = "Yoni";

    std::cout << nombre;

    return 0;
}
03 // OPERADORES

Operadores matemáticos

Puedes realizar operaciones utilizando +, -, *, / y %. 

int a = 10;
int b = 3;

std::cout << a + b;
std::cout << a - b;
std::cout << a * b;
std::cout << a / b;
std::cout << a % b;
04 // CONDICIONALES

if, else if y else

Permiten tomar decisiones dependiendo del estado de una condición. 

int edad;

std::cin >> edad;

if (edad >= 18) {

    std::cout << "Mayor de edad";

} else {

    std::cout << "Menor de edad";

}
05 // SWITCH

Crear menús

Switch resulta útil cuando tienes varias opciones posibles. 

int opcion;

std::cin >> opcion;

switch(opcion) {

    case 1:
        std::cout << "Jugar";
        break;

    case 2:
        std::cout << "Configuracion";
        break;

    default:
        std::cout << "Invalido";

}
06 // BUCLES

for

Los bucles permiten repetir instrucciones varias veces. 

for(int i = 1; i <= 10; i++) {

    std::cout << i << "\n";

}
07 // FUNCIONES

Crear funciones

Una función permite reutilizar código. 

int sumar(int a, int b) {

    return a + b;

}

int main() {

    int resultado = sumar(5, 7);

    std::cout << resultado;

}
08 // ARRAYS

Arrays

Un array almacena varios elementos del mismo tipo. 

int numeros[5] = {
    10, 20, 30, 40, 50
};

std::cout << numeros[0];
09 // STRING

Texto

std::string permite trabajar fácilmente con cadenas. 

#include <string>

std::string nombre = "Yoni";

std::cout << nombre;

std::cout << nombre.length();
10 // VECTOR

std::vector

Vector es un contenedor dinámico de la biblioteca estándar. 

#include <vector>

std::vector<int> numeros;

numeros.push_back(10);
numeros.push_back(20);
numeros.push_back(30);

for(int n : numeros) {

    std::cout << n << "\n";

}
