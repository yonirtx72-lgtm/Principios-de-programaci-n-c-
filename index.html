01 // VARIABLES

Variables y tipos

Las variables almacenan información. Algunos tipos comunes son int, double, char, bool y string. 

int edad = 15;
double precio = 99.99;
char letra = 'A';
bool activo = true;
02 // OPERADORES

Operadores

Los operadores permiten realizar cálculos y comparaciones. 

int a = 10;
int b = 3;

cout << a + b;
cout << a - b;
cout << a * b;
cout << a / b;
cout << a % b;
03 // CONDICIONALES

if y else

Las condiciones permiten que el programa tome decisiones. 

int edad;

cin >> edad;

if(edad >= 18){

    cout << "Mayor de edad";

}else{

    cout << "Menor de edad";

}
04 // BUCLES

for

Los bucles permiten repetir instrucciones. 

for(int i = 1; i <= 10; i++){

    cout << i << "\n";

}
05 // FUNCIONES

Funciones

Una función permite reutilizar código. 

int sumar(int a, int b){

    return a + b;

}

int main(){

    cout << sumar(5,7);

}
06 // ARRAYS

Arrays

Un array almacena varios elementos del mismo tipo. 

int numeros[5] = {
    10,20,30,40,50
};

cout << numeros[0];
07 // STRINGS

Cadenas de texto

std::string permite almacenar y manipular texto. 

#include <string>

string nombre = "Yoni";

cout << nombre;
cout << nombre.length();
08 // VECTOR

std::vector

Vector es un contenedor dinámico de la biblioteca estándar. 

#include <vector>

vector<int> numeros;

numeros.push_back(10);
numeros.push_back(20);
numeros.push_back(30);

for(int n : numeros){

    cout << n << "\n";

}
09 // PUNTEROS

Punteros

Un puntero almacena la dirección de memoria de otra variable. 

int numero = 50;

int* ptr = №

cout << *ptr;
10 // REFERENCIAS

Referencias

Una referencia es otro nombre para una variable existente. Puede utilizarse para modificar directamente su valor. 

int numero = 10;

int& referencia = numero;

referencia = 50;

cout << numero;
11 // STRUCT

Struct

Una estructura permite agrupar diferentes datos relacionados dentro de un mismo tipo. 

struct Persona{

    string nombre;
    int edad;

};

int main(){

    Persona persona;

    persona.nombre = "Yoni";
    persona.edad = 15;

    cout << persona.nombre;

}
12 // CLASES

Clases y objetos

Las clases permiten crear objetos que combinan datos y funciones. 

class Persona{

public:

    string nombre;

    void saludar(){

        cout << "Hola";

    }

};

int main(){

    Persona p;

    p.nombre = "Yoni";

    p.saludar();

}
13 // CONSTRUCTORES

Constructores

Un constructor se ejecuta automáticamente cuando se crea un objeto. 

class Persona{

public:

    string nombre;

    Persona(string n){

        nombre = n;

    }

};

int main(){

    Persona p("Yoni");

    cout << p.nombre;

}
14 // HERENCIA

Herencia

La herencia permite que una clase reutilice características y funciones de otra clase. 

class Animal{

public:

    void comer(){

        cout << "Comiendo";

    }

};

class Perro : public Animal{

public:

    void ladrar(){

        cout << "Guau";

    }

};
15 // POLIMORFISMO

Polimorfismo

El polimorfismo permite que diferentes clases respondan de distintas maneras a una misma función. 

class Animal{

public:

    virtual void sonido(){

        cout << "Sonido";

    }

};

class Perro : public Animal{

public:

    void sonido() override{

        cout << "Guau";

    }

};
16 // STL

Standard Template Library

La STL proporciona herramientas y contenedores que facilitan el desarrollo de programas. 

#include <vector>
#include <algorithm>

vector<int> numeros = {
    5, 2, 8, 1, 4
};

sort(
    numeros.begin(),
    numeros.end()
);

for(int n : numeros){

    cout << n << " ";

}
17 // TEMPLATES

Templates

Los templates permiten crear funciones y clases que pueden trabajar con diferentes tipos de datos. 

template <typename T>

T mayor(T a, T b){

    return (a > b) ? a : b;

}

int main(){

    cout << mayor(10, 20);

}
18 // LAMBDAS

Funciones Lambda

Las lambdas permiten crear pequeñas funciones directamente dentro del código. 

auto sumar = [](int a, int b){

    return a + b;

};

cout << sumar(5, 10);
19 // SMART POINTERS

Smart Pointers

Los punteros inteligentes ayudan a administrar automáticamente la memoria. 

#include <memory>

auto numero =
    std::make_unique<int>(100);

cout << *numero;
20 // THREADS

Programación concurrente

Los threads permiten ejecutar diferentes tareas de manera concurrente. 

#include <thread>
#include <iostream>

void tarea(){

    std::cout << "Ejecutando...";

}

int main(){

    std::thread hilo(tarea);

    hilo.join();

    return 0;

}
